# Storm Browser

Storm Browser is an open source, WebView-based web browser for Android focused on privacy and customization.

## Features

- Modern, clean UI
- Ad and tracker blocking options
- Privacy-focused settings
- Customizable navigation and homepage
- Open source (MPL-2.0)

## Building

Import the project into Android Studio, or build from the command line:

```bash
./gradlew assembleDebug
```

## Notes

This project was rebranded as Storm Browser. Review service endpoints, privacy text, and store/distribution metadata before release.
